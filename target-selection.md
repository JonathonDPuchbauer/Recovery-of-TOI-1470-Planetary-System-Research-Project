# Target Selection

## TARGET

**TOI-1470**

## Reason for selection

I selected TOI-1470 as the initial target for this project because it is a multi-planetary system with TESS observations across multiple sectors.

The system provides an opportunity to investigate more than one transit signal and compare results across separate TESS observations. It also provides an opportunity to incorporate Target Pixel File analysis alongside the standard light curves.

## Target Selection Criteria

The target was evaluated according to the following criteria:

- Multiple TESS observations
- 2-minute SPOC observations where available
- Suitable photometric data for transit searches
- Available Target Pixel Files
- A sufficiently bright host star for useful photometry
- An interesting multi-planetary system rather than a single isolated transit signal

## Analysis Approach

I will initially analyze the TESS observations without using the published planetary parameters to guide the transit search. After completing the independent analysis, I will compare my recovered properties with published measurements.

Specific TESS sectors, cadence, and data products selected will be documented after completing the MAST data review.
